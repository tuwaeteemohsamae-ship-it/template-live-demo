StoreOS — Owner Backend Dashboard, page 1.1 "How's my store today?"

Users: Owner and Staff  ·  Sources: D1.1, D1.4, D1.14

Goal: Open the page and know within 5 seconds — (1) Is there pending work? (2) Is the website healthy? (3) Want to fix something? Tap and go. This is not a graphs page.

Auto pending tasks: unanswered customer messages · promos expiring within 3 days · items with prices unchanged for 60+ days · items with missing photos.

4 job shortcuts: Edit Prices (1.2), Promotions (1.3), Menu & Photos (1.4) — opening the correct sheet in ≤ 2 taps.

Close store today / by period (F4): choose "Today · Tomorrow · Until date…" with a customer-facing message (default text provided) — appears on storefront within 5 seconds; reopen with one tap.

Today in 3 numbers (vs yesterday) → Analytics (1.8) · 1-line site status → Website Health (1.9) · 5 latest activities in plain language with "Undo" where possible.

[P2] "Tell me what to fix" command bar (D1.14): type "iced latte to 75" → system converts it into a structured change → shows before/after summary → owner confirms before anything is written. Supports: price edits · item status changes · promo drafts · store closure. Never writes data without confirmation. Logged in ChangeLog as "ordered via message".

UX: Mobile top-to-bottom: greeting + status → pending tasks (≤3 cards) → 4 large shortcuts (2×2) → 3 metric cards → site status → recent activity → upsell card (1.10) → demo mission bar (3.3). Desktop: 2 columns, left = sections 1–4, right = 5–7 + 390px site preview.

States: New/empty store → 3-step setup checklist · loading → skeleton · offline → show last cached data.

Pass criteria: ready ≤ 3s on 4G · reach any edit point ≤ 2 taps · "Close store today" banner visible on storefront ≤ 5s.
