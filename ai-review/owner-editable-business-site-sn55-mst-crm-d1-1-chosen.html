Web App Information

Rimjai Shop Manager · Owner Console
Version 2.4.1 · Standalone HTML template · Page 1.1 "Today at the Shop"

Users: Shop owner and staff. The page answers three questions in five seconds: are there pending tasks, is the website healthy, and what can be fixed right now.

Key features: automatic pending-task detection (unanswered customer leads, promos ending within 3 days, prices not reviewed for 60+ days, items missing photos), four big shortcuts (edit price, start promo, change photo, close store today), store closure for today, tomorrow, or until a chosen date with a customer message that appears on the storefront instantly and one-tap reopen, today's three key numbers with day-over-day comparison (visitors, contacts, new interested customers), website status line with last check and nightly backup result, recent activity feed with one-tap undo, quick command box that converts plain text into a structured change that must be confirmed before saving, demo mode with guided missions, onboarding checklist for new stores, skeleton loading, and an offline cached-data banner.

Technical summary: single-file standalone HTML, Tailwind CSS with a shadcn-style component system, Plus Jakarta Sans and Inter from Google Fonts, Bootstrap Icons font icons, vanilla JavaScript. Fully responsive for desktop, tablet, and mobile. Currency is displayed in Thai baht (฿).
