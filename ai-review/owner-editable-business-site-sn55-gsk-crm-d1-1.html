Sala Console · v2.4 · owner back office

1.1 Owner back office · Home “How is my shop today?”
/app · Users: owner, staff · Source: D1.1, D1.4, D1.14

Goal. Open it and know within 5 seconds (1) whether anything is pending, (2) whether the website is fine, (3) that whatever you want to fix is one tap away — not a page of graphs.

Functions.
· Show pending work automatically: customer enquiries not yet answered · promotions ending soon (≤ 3 days) · items whose price has not been corrected for over 60 days · items with a missing photo.
· Four “work” shortcuts → pages 1.2 / 1.3 / 1.4, opening the correct sheet immediately.
· Close the shop today / close for a range (F4): choose “today · tomorrow · until date…”, add a message to customers (a default message is provided) → appears on 2.1 / 2.5 immediately · reopen the shop with one tap.
· Three numbers for today (compared with yesterday) → tap through to 1.8.
· Website status on one line → tap through to 1.9.
· Last five activities in plain language + an “undo” button on every item that can be undone.
· [P2] A “tell me what to fix” box (D1.14): type “iced latte up to 75” → the system turns it into a structured change → shows a before → after summary → the owner confirms. Supported only: change a price · change an item’s status · draft a promotion · close the shop · it never writes data without confirmation · recorded in the ChangeLog as “ordered by message”.

UX/UI (mobile, top to bottom).
1 · Greeting + shop status — “Good morning, Khun Ek” · date in B.E. · badge “Shop open / Closed today” + a switch to close the shop today.
2 · Pending work (max 3 cards) — single-row card: icon + text + one button (“Reply” · “Renew promo” · “Check price”), ordered by urgency · when empty: “Nothing pending today”.
3 · Four large shortcuts (2×2) — change a price · start a promotion · change a photo · close the shop today · buttons ≥ 72 px.
4 · Today in numbers — 3 metric cards: visitors · contacts (call + LINE + directions + form) · new leads · ▲▼ compared with yesterday.
5 · Website status — “Site fine · last checked 05:00 · backup last night succeeded”.
6 · Recent activity — “Somchai changed Iced latte ฿70 → ฿75 · 14:05 [Undo]”.
7 · One follow-on card (only when the threshold is met) → 1.10.
8 · Mission strip (demo mode only) — “Mission 1/3” → 3.3.
Desktop: two columns, left = 1–4, right = 5–7 + a 390 px site preview.

States. New or empty shop → a 3-step starting checklist (check shop info 1.6 → add an item 1.2 → try a price change) · loading → skeleton · offline → the last cached data.

Links. Entered from 1.12 (after sign-in) and 3.3 (demo) → continue to 1.2 · 1.3 · 1.4 · 1.6 · 1.7 · 1.8 · 1.9 · 1.10 · the “View site” button → 2.1.

Presets. Different leading pending work — A: table bookings / message orders · B: appointment requests awaiting confirmation · C: unanswered quote requests.

Pass criteria. Ready in ≤ 3 s on 4G · any fix reachable in ≤ 2 taps · pressing “Close today” makes 2.1 show the banner within ≤ 5 s.

1.1 หลังบ้านเจ้าของร้าน | หน้าแรก "วันนี้ร้านเป็นไง"
/app · ผู้ใช้: เจ้าของ, พนักงาน · ที่มา: D1.1, D1.4, D1.14

เป้าหมาย: เปิดมาแล้วรู้ใน 5 วินาทีว่า (1) มีงานค้างไหม (2) เว็บปกติไหม (3) อยากแก้อะไรกดได้ทันที — ไม่ใช่หน้ากราฟ

Function
แสดงงานค้างอัตโนมัติ: ลูกค้าสนใจที่ยังไม่ตอบ · โปรใกล้หมด (≤ 3 วัน) · รายการที่ราคาไม่ถูกแก้เกิน 60 วัน · รายการที่รูปหาย
ทางลัด "งาน" 4 ปุ่ม → ไปหน้า 1.2 / 1.3 / 1.4 พร้อมเปิด sheet ที่ถูกต้องทันที
ปิดร้านวันนี้ / ปิดตามช่วง (F4): เลือก "วันนี้ · พรุ่งนี้ · ถึงวันที่…" + ข้อความถึงลูกค้า (มีข้อความเริ่มต้นให้) → ขึ้นบน 2.1 / 2.5 ทันที · เปิดร้านกลับด้วย 1 แตะ
สรุป 3 ตัวเลขของวันนี้ (เทียบเมื่อวาน) → แตะไป 1.8
สถานะเว็บ 1 บรรทัด → แตะไป 1.9
กิจกรรมล่าสุด 5 รายการ (ภาษาคน) + ปุ่ม "ย้อนกลับ" ต่อรายการที่ย้อนได้
[P2] ช่อง "บอกสิ่งที่อยากแก้" (D1.14): พิมพ์ "ลาเต้เย็นขึ้นเป็น 75" → ระบบแปลงเป็นการเปลี่ยนที่มีโครงสร้าง → แสดงสรุป ก่อน→หลัง → เจ้าของกดยืนยัน · รองรับเฉพาะ: แก้ราคา · เปลี่ยนสถานะรายการ · ร่างโปร · ปิดร้าน · ห้ามเขียนข้อมูลเองโดยไม่ยืนยัน · บันทึกใน ChangeLog ว่า "สั่งด้วยข้อความ"

UX/UI (มือถือ ไล่จากบนลงล่าง)
1 · ทักทาย + สถานะร้าน — "สวัสดีครับ คุณเอก" · วันที่ พ.ศ. · ป้าย "ร้านเปิดอยู่ / ปิดวันนี้" + สวิตช์ปิดร้านวันนี้
2 · งานค้าง (สูงสุด 3 การ์ด) — การ์ดแถวเดียว: ไอคอน + ข้อความ + ปุ่มเดียว ("ตอบเลย" · "ต่ออายุโปร" · "ตรวจราคา") เรียงตามความเร่งด่วน · ไม่มีงาน → "วันนี้ไม่มีงานค้าง"
3 · ทางลัด 4 ปุ่มใหญ่ (2×2) — แก้ราคา · เปิดโปร · เปลี่ยนรูป · ปิดร้านวันนี้ · ปุ่ม ≥ 72 px
4 · วันนี้ในตัวเลข — Metric card 3 ใบ: คนเข้าชม · คนติดต่อ (โทร+LINE+นำทาง+ฟอร์ม) · ลูกค้าสนใจใหม่ · ▲▼ เทียบเมื่อวาน
5 · สถานะเว็บ — "เว็บปกติ · ตรวจล่าสุด 05:00 น. · สำรองข้อมูลเมื่อคืนสำเร็จ"
6 · กิจกรรมล่าสุด — "สมชาย แก้ ลาเต้เย็น ฿70 → ฿75 · 14:05 น. [ย้อนกลับ]"
7 · การ์ดต่อยอด (เฉพาะเมื่อถึงเกณฑ์) — 1 การ์ดย่อ → 1.10
8 · แถบภารกิจ (เฉพาะโหมดเดโม) — "ภารกิจ 1/3" → 3.3
เดสก์ท็อป: 2 คอลัมน์ ซ้าย = 1–4, ขวา = 5–7 + พรีวิวเว็บ 390 px

สถานะ: ร้านใหม่/ว่าง → เช็กลิสต์เริ่มต้น 3 ข้อ (ตรวจข้อมูลร้าน 1.6 → เพิ่มรายการ 1.2 → ลองแก้ราคา) · โหลด → skeleton · ออฟไลน์ → แสดงข้อมูลล่าสุดที่แคชไว้

เชื่อมโยง: เข้ามาจาก 1.12 (หลังล็อกอิน), 3.3 (เดโม) → ไปต่อ 1.2 · 1.3 · 1.4 · 1.6 · 1.7 · 1.8 · 1.9 · 1.10 · ปุ่ม "ดูเว็บ" → 2.1

พรีเซ็ต: งานค้างเด่นต่างกัน — A: ลูกค้าจองโต๊ะ/ทักสั่ง · B: คำขอนัดรอยืนยัน · C: คำขอใบเสนอราคาที่ยังไม่ตอบ

เกณฑ์ผ่าน: พร้อมใช้ ≤ 3 วิ บน 4G · ทางลัดไปถึงจุดแก้ ≤ 2 แตะ · กด "ปิดร้านวันนี้" แล้ว 2.1 แสดงแบนเนอร์ ≤ 5 วิ
